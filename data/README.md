## 🔍 使用方法

### 基本的な読み込み（JavaScript）

```javascript
// 組織データの読み込み
const organizations = require('./organizations.json');

// 特定組織の検索
const isis = organizations.organizations.find(org => org.id === 'isis');
console.log(isis.currentStatus.summary);

// 活動中の組織のフィルタリング
const activeOrgs = organizations.organizations.filter(
  org => org.status === '活動継続中'
);

// イベントデータの読み込み
const events = require('./events.json');

// 2024年以降のイベント
const recentEvents = events.events.filter(
  event => event.date >= '2024-01-01'
);

// 国別データの読み込み
const countries = require('./countries.json');

// 高脅威国の抽出
const highThreat = countries.countries.filter(
  country => country.threatLevel.includes('高')
);
```

### Python での使用例

```python
import json

# 組織データの読み込み
with open('organizations.json', 'r', encoding='utf-8') as f:
    organizations = json.load(f)

# 地域別の組織数
from collections import Counter
regions = Counter([org['region'] for org in organizations['organizations']])
print(regions)

# 最新イベントの取得
with open('events.json', 'r', encoding='utf-8') as f:
    events = json.load(f)

latest_events = sorted(events['events'], key=lambda x: x['date'], reverse=True)[:5]
for event in latest_events:
    print(f"{event['date']}: {event['title']['ja']}")
```
